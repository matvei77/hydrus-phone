# Product

Hydrus Pocket optimizes the short mobile loop: compose a precise Hydrus search, scan a virtualized contact sheet, open mixed media, and make safe organizational changes. Android Chrome portrait is primary; landscape and desktop are responsive secondary surfaces.

Included in v0.1: display-tag autocomplete, positive/negative/OR/system predicates, filters, all specified sort fields, bounded results and metadata, images/video/audio/fallback viewing, Range seeking, grouped tag inspection, local tag add/remove, archive endpoints, saved/recent searches, PWA install/cache/update plumbing, explicit connection states, and local settings.

Excluded deliberately: file deletion, repository petitions, moderation, router port forwarding, and public exposure.
