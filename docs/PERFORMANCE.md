# Performance

Release defaults: 500 search results, 128 browser metadata batch, 256 gateway ceiling, four virtualized overscan rows, three portrait columns, and 20-second Hydrus timeout. The in-memory metadata cache is capped at 768 most-recently-used files; older entries are refetched if revisited. Once the current media is ready, six workers fill a page-session 200 MB LRU image cache in next/current/previous proximity order across as many as 160 surrounding positions. Individual cached blobs are capped at 24 MB. The cache survives viewer close/reopen and is released with the browser page session. The next two videos warm metadata and poster frames without downloading full videos. Thumbnail Cache Storage is capped at 300 entries and seven days. Original media and API responses are `no-store` and never enter the offline cache.

V1.0.0 production browser bundle (2026-07-11): 337.06 KiB application JavaScript / 106.45 KiB gzip, 5.81 KiB update helper / 2.40 KiB gzip, and 18.86 KiB CSS / 4.97 KiB gzip. The PWA precache is 354.02 KiB. A representative 3200×1800 JXL rendered through Hydrus to quality-95 JPEG in 435 ms and 1.06 MB on the production host; repeat renders benefit from Hydrus' image cache and the next eligible files use the viewer's session-wide RAM cache. Target-phone landscape frame pacing, extended video-start latency, and gateway long-stream memory remain post-v1 operational measurements.
