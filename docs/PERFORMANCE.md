# Performance

Release defaults: 500 search results, 128 browser metadata batch, 256 gateway ceiling, four virtualized overscan rows, three portrait columns, and 20-second Hydrus timeout. The in-memory metadata cache is capped at 768 most-recently-used files; older entries are refetched if revisited. Once the current media is ready, the viewer looks ahead up to 20 positions and holds at most 16 images, 8 MB each / 48 MB total, in volatile RAM with three concurrent requests. The next two videos warm metadata and poster frames without downloading full videos. All lookahead blobs are revoked when the viewer closes. Thumbnail Cache Storage is capped at 300 entries and seven days. Original media and API responses are `no-store` and never enter the offline cache.

RC5 production browser bundle (2026-07-10): 336.17 KiB application JavaScript / 106.07 KiB gzip, 5.81 KiB update helper / 2.40 KiB gzip, and 18.82 KiB CSS / 4.97 KiB gzip. The PWA precache is 353.12 KiB. Target-phone frame pacing, video-start latency, and gateway long-stream memory still require the physical Android verification recorded in the release checklist.
