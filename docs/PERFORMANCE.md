# Performance

Release defaults: 500 search results, 128 browser metadata batch, 256 gateway ceiling, four virtualized overscan rows, three portrait columns, and 20-second Hydrus timeout. The in-memory metadata cache is capped at 768 most-recently-used files; older entries are refetched if revisited. Six workers fill a page-session 200 MB LRU media cache in next/current/previous proximity order across as many as 160 surrounding positions. The current item and two nearest items in each direction are protected from speculative eviction. Individual cached blobs are capped at 24 MB. Eligible videos buffer fully before playback and nearby videos warm after the current media is ready, avoiding repeated network range fetches while seeking or replaying. The cache survives viewer close/reopen and is released with the browser page session. Thumbnail Cache Storage is capped at 300 entries and seven days. Original media and API responses are `no-store` and never enter the offline cache.

V1.2.2 production browser bundle (2026-07-11): 338.43 KiB application JavaScript / 106.92 KiB gzip, 5.81 KiB update helper / 2.40 KiB gzip, and 19.36 KiB CSS / 5.06 KiB gzip. The PWA precache is 355.86 KiB. A representative 3200×1800 JXL rendered through Hydrus to quality-95 JPEG in 435 ms and 1.06 MB on the production host; repeat renders benefit from Hydrus' image cache and the next eligible files use the viewer's session-wide RAM cache. Justified gallery rows are computed from metadata dimensions and virtualized with exact per-row height estimates. Target-phone landscape frame pacing and gateway long-stream memory remain post-v1 operational measurements.
