# Accessibility

Controls have accessible names, native inputs/selects/radio/checkbox semantics, visible focus outlines, 48 px minimum primary targets, and non-color connection text. Keyboard search supports arrows, Enter, Escape, and Backspace; viewer supports Escape and arrow keys. Layout remains usable at narrow widths and respects reduced motion.

Remaining release-device audit: Android TalkBack order/announcements, 200% desktop zoom, Chrome contrast audit, and native media-control gesture conflict checks.
