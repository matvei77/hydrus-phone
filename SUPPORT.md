# Support

Hydrus Pocket is community-supported software.

Use GitHub Issues for reproducible bugs and focused feature proposals. Before filing an issue:

1. Update to the latest Hydrus Pocket release.
2. Confirm Hydrus is running and `scripts/health.ps1` succeeds.
3. Test the local health URL before diagnosing Tailscale.
4. Review [Operations](docs/OPERATIONS.md) and [Security](SECURITY.md).

Include Hydrus version, Client API version, Hydrus Pocket version, Windows version, browser/device, relevant non-sensitive logs, and exact reproduction steps. Redact access/session keys, hashes, tags, filenames, private DNS names, IP addresses, and collection screenshots.

The supported host platform for the initial public release is Windows 10/11. Android Chrome is primary; Chromium desktop is secondary. Linux, macOS, Docker, public internet exposure, and Tailscale Funnel are not currently supported.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md), not through a public issue.
